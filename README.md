# PINN
Данный репозиторий содержит реализацию моделей Physics-Informed Neural Networks (PINN) — подхода, в котором нейронные сети обучаются с учётом физических законов, заданных в виде дифференциальных уравнений. Это позволяет получать решения, согласованные с физикой процесса при ограниченном количестве данных.

Проект ориентирован на разработку, обучение и тестирование PINN и связанных архитектур (включая MDN), а также на эксперименты с функциями потерь и синтетическими данными.

# Структура проекта
```
PINN/
├── src/
│   ├── loss/        # функции потерь для PINN и MDN
│   ├── models/      # реализованные модели
│   ├── networks/    # архитектуры моделей
│   └── plots/       # (устаревшее) визуализация для 1D PINN
├── irrelevant/      # реализация одномерной PINN (неактуально для промышленности)
├── data_generator.py   # генерация синтетических данных
└── training.ipynb      # обучение и тестирование моделей
```

Примечание: Папка plots не используется в актуальной версии, её содержимое носит демонстрационный характер PINN, обученной на одномерных данных.
